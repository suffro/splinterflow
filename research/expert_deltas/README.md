# Phase 5C: exact shared expert bases and progressive expert deltas

Research code, not a runtime. It asks two separate questions about Moonlight-16B-A3B's routed experts
(`BF16_REFERENCE`, the Phase 4B/5A model at its pinned revision):

1. **Exact structural reuse (stage 5C1).** Can a shared resident base plus exact, losslessly encoded per-expert deltas
   move fewer bytes than the published checkpoint and than competent independent compression of the experts?
2. **Certified adaptive materialization (stage 5C2).** Can a partially read exact representation (the pages of an
   expert's bit planes read so far, plus resident metadata) decide the same token as the fully materialized reference
   while some bytes are never read? Stage 5C2 is a structural diagnostic in real arithmetic, never a certified BF16
   result.

Configuration and gates: `configs/phase5c-expert-deltas.yaml` (thresholds fixed before any measurement). Results:
`experiments/phase5c/`. Report: `.context/history/2026-10-08-awpmi-phase5c-report.md`; decision 0011.

## Environment

The Weightsift environment (root `pyproject.toml`): it reads the checkpoint through `awpmi`'s safetensors layout and
reuses Phase 5A's oracle and capture. The dependency group `research` (a default group) adds the codecs and SciPy:

```bash
python -m uv sync
python -m uv run python -m pytest research/expert_deltas/tests        # this directory's tests
```

## Pipeline

```bash
export PYTHONHASHSEED=1 PYTHONIOENCODING=utf-8
# 5C1-A: the codec probe (8 experts of layer 26; ~10 min)
python -m uv run python research/expert_deltas/probe_codec.py --output experiments/phase5c/probe-codec
# 5C1-B: structural reuse (4 layers × 64 experts, one process per layer, ~20 min each), the replay, the report
R=experiments/phase5c/structure-run1
python -m uv run python research/expert_deltas/structure_run.py --output $R --stage prepare
for L in 26 1 9 17; do python -m uv run python research/expert_deltas/structure_run.py --output $R --stage layer --layer $L; done
python -m uv run python research/expert_deltas/structure_run.py --output $R --stage replay
python -m uv run python research/expert_deltas/structure_run.py --output $R --stage report
# 5C2-A: the progressive feasibility probe (Phase 5A2's three samples; needs experiments/phase5a2/capture/capture.safetensors,
# regenerated by benchmarks/expert_oracle.py --stage capture and checked against Phase 5A run1's digest)
python -m uv run python research/expert_deltas/progressive_probe.py --output experiments/phase5c/progressive-probe
```

## Modules (`expert_deltas/`)

| Module | Role |
| --- | --- |
| `bits.py` | Exact transforms of BF16 bit patterns (uint16): XOR and modular deltas, byte split, bit planes; prefix intervals (the values a weight can take once its top t bits are known) |
| `codecs.py` | zstd (python-zstandard: one frame per page, its C-threaded batch API, trained dictionaries) and LZ4 (python-lz4 block format); `PageFile`, independently decodable pages with offsets and lengths |
| `source.py` | The checkpoint tensor by tensor: safetensors headers for offsets, two independent read paths (positioned reads; safetensors' `safe_open`), file sha256 against the publisher's |
| `compression.py` | Blocks (rows, pages, tensors, experts as stored) × transforms × codecs; `measure` compresses, decodes, restores, finishes deltas and compares every reconstruction bit for bit; `decode_throughput` (decompression, CPU and GPU restoration timed apart) |
| `census.py`, `structure.py` | Bit fields' entropies; shared contexts; the cross-expert spectrum; sign and exponent agreement; pairwise delta costs; base strategies (first expert, medoid, best of three, SciPy clusters, a synthetic median); the neuron-permutation diagnostic |
| `replay.py` | Phase 5A's routing trace through per-layer LRU caches (Weightsift's `PageCache`, size-only entries) of experts, deltas and bases; bases pinned, bounded or on the GPU |
| `progressive.py` | Bit-plane pages and steps; the box set of every weight consistent with what is read (from a read view whose unread bits are poisoned); the closed-form exact minimum of the real-arithmetic decision Δ·y over a box set; witnesses (the minimizer as weights) |
| `records.py` | Environment, source-tree hashes (Weightsift's plus this directory), digests |

Drivers: `probe_codec.py` (5C1-A), `structure_run.py` and `structure_report.py` (5C1-B), `progressive_probe.py` (5C2-A).

## What is reused, what Weightsift adds

Reused as published: zstandard 0.25 (libzstd 1.5.7: compression levels, frames, `train_dictionary`, batch APIs), lz4
4.4.5 (liblz4 1.9.4), SciPy 1.18 (`scipy.cluster.hierarchy`), PyTorch (every GPU computation: histograms, Gram matrices,
SVD, the GPU restoration, the exact optimum's matrix products), NumPy (`packbits`), safetensors. From Weightsift:
`awpmi.storage.layout` (headers), `awpmi.models.checkpoint`/`awpmi.storage.pack` (publisher digests, direct-read sha256),
`awpmi.storage.cache.PageCache` (the replay), `awpmi.oracle.experts.decode_sample` (Phase 5A's reference, recomputed
bitwise), Phase 5A's capture and Phase 5A2's comparison records.

Written here: the exact bit transforms and their prefix intervals; the page layout; the measurement drivers; the replay
model; the box sets and their closed-form optimum and witnesses (one row at a time, no verifier). No compression
algorithm, no clustering, no verifier, no kernel.

## Invariants (tested)

- Every transform restores all 65,536 BF16 patterns bit for bit; prefix intervals equal brute force for every pattern
  and prefix length, contain the value, and only shrink as bits are read.
- A page decodes from its own byte range: every other byte poisoned changes nothing; batch frames equal single frames.
- Every reconstruction in every measurement is compared with the safetensors copy bit for bit (a failure stops the stage).
- The replay charges every miss: experts, deltas and bases (cold, pinned, thrashing, several bases per expert).
- The box set never depends on an unread bit; the closed-form optimum equals enumeration on toys; no random point of a
  set goes below it; a witness lies in its set and attains it; more planes never lower it, and every plane read gives
  the truth.
